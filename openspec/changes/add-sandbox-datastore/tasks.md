## 1. Postgres для сэндбоксов

- [x] 1.1 Поднять на VPS Postgres в сети сэндбоксов с постоянным томом и паролем администратора из секретов; проверка — сервер отвечает, данные переживают перезапуск контейнера
- [ ] 1.2 Подключить процесс сведения к сети сэндбоксов; проверка — он видит Postgres, а платформа и реестр в этой сети по-прежнему недоступны (спека `sandbox-datastore`)

## 2. Реквизиты в схеме платформы

- [x] 2.1 Миграция: имя базы, имя пользователя, пароль и ключ подписи сессий на каждый сэндбокс; проверка — миграция накатывается на чистую базу
- [x] 2.2 Реализовать генерацию реквизитов при создании сэндбокса; проверка — тест, что значения создаются один раз и не меняются при повторном вызове

## 3. Выдача базы

- [x] 3.1 Реализовать создание базы и пользователя с правами только на неё; проверка — тесты на создание и на повторный вызов для уже существующей базы
- [x] 3.2 Отобрать у пользователя право видеть чужие базы; проверка — подключение его реквизитами не даёт открыть чужую базу (спека `sandbox-datastore`)
- [x] 3.3 Выдавать базу и сэндбоксам, созданным до этого изменения; проверка — существующий сэндбокс получает базу при первом запуске после выката
- [ ] 3.4 Удалять базу и пользователя вместе с сэндбоксом; проверка — после удаления записи база исчезает

## 4. Передача в контейнер

- [x] 4.1 Передавать строку подключения, ключ подписи и публичный адрес при запуске; проверка — окружение запущенного контейнера содержит их, и при повторном запуске значения те же (спека `sandbox-runtime`)
- [x] 4.2 Не запускать сэндбокс без реквизитов, сообщая это состоянием; проверка — тест, что отсутствие базы даёт понятное состояние, а не падение процесса сведения
- [x] 4.3 Убедиться, что реквизиты не попадают в ответы платформы и страницу состояния; проверка — тест на состав ответа

## 5. Приёмка

- [ ] 5.1 Из работающего сэндбокса записать данные, дождаться засыпания, разбудить и прочитать; проверка — данные на месте
- [ ] 5.2 Из работающего сэндбокса попытаться открыть чужую базу и перечислить базы; проверка — обе попытки безуспешны
- [ ] 5.3 Проверить, что предел одновременных сэндбоксов не пострадал; проверка — три сэндбокса и Postgres укладываются в свободную память
