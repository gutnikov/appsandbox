## ADDED Requirements

### Requirement: Шаблон вправе рассчитывать на базу

Приложение в шаблоне SHALL использовать базу по строке подключения из окружения и SHALL приводить её схему в нужный вид самостоятельно при запуске. Пользователь сэндбокса MUST NOT быть обязан выполнять миграции вручную.

#### Scenario: Первый запуск сэндбокса

- **WHEN** сэндбокс с пустой базой запускается впервые
- **THEN** схема создаётся сама, и приложение начинает отвечать

#### Scenario: Новая версия с изменённой схемой

- **WHEN** пользователь добавил миграцию и опубликовал новый образ
- **THEN** при запуске новая миграция применяется без его участия
