## ADDED Requirements

### Requirement: Контейнер получает реквизиты своего хранилища

При запуске сэндбокса платформа SHALL передавать в контейнер строку подключения к его базе, его постоянный ключ подписи сессий и его собственный публичный адрес. Значения SHALL передаваться окружением, а не образом.

#### Scenario: Запуск сэндбокса

- **WHEN** платформа запускает контейнер сэндбокса
- **THEN** в его окружении есть строка подключения, ключ подписи и публичный адрес сэндбокса
- **AND** те же значения передаются при каждом следующем запуске

#### Scenario: Реквизитов нет

- **WHEN** для сэндбокса почему-то нет базы или секретов
- **THEN** платформа не запускает контейнер и сообщает об этом состоянием, а не падением
