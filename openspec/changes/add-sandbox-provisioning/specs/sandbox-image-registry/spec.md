## Purpose

Реестр образов сэндбоксов и правила доступа к нему: куда сборка из репозитория пользователя складывает образ и на каком основании ей это разрешено. Реестр принадлежит платформе, поэтому она сама решает, кто и во что может писать, и не зависит от чужой модели видимости пакетов.

## ADDED Requirements

### Requirement: Реестр принимает образы сэндбоксов

Платформа SHALL предоставлять реестр образов, доступный по HTTPS, в который публикуются образы сэндбоксов. Каждому сэндбоксу SHALL соответствовать ровно один образ, именуемый по имени сэндбокса.

#### Scenario: Публикация образа сэндбокса

- **WHEN** сборка публикует образ под именем существующего сэндбокса
- **THEN** реестр принимает образ
- **AND** образ доступен платформе для последующего скачивания

### Requirement: Право на публикацию выводится из удостоверения запуска

Реестр MUST NOT принимать публикацию по долгоживущим учётным данным. Право на запись SHALL выдаваться в обмен на OIDC-удостоверение запуска GitHub Actions. Платформа SHALL проверять подпись удостоверения, его издателя, срок действия и предназначенную ей аудиторию.

#### Scenario: Корректное удостоверение

- **WHEN** сборка предъявляет действующее удостоверение запуска, выданное GitHub для репозитория сэндбокса
- **THEN** платформа выдаёт токен с правом записи
- **AND** публикация проходит

#### Scenario: Удостоверение с чужой аудиторией или истёкшим сроком

- **WHEN** предъявлено удостоверение с неверной подписью, чужим издателем, чужой аудиторией или истёкшим сроком действия
- **THEN** право на запись не выдаётся
- **AND** публикация отклоняется

### Requirement: Публиковать можно только образ своего сэндбокса

Выдаваемое право SHALL быть ограничено единственным образом — тем, чьё имя соответствует сэндбоксу, созданному из репозитория, указанного в удостоверении. Платформа SHALL сверять репозиторий из удостоверения с записью о сэндбоксе в своём реестре имён и SHALL отказывать, если такого сэндбокса нет.

#### Scenario: Попытка записи в чужой образ

- **WHEN** сборка из репозитория одного сэндбокса запрашивает право на запись в образ другого сэндбокса
- **THEN** право не выдаётся, и попытка публикации отклоняется

#### Scenario: Репозиторий не соответствует ни одному сэндбоксу

- **WHEN** удостоверение выдано для репозитория, которому не соответствует ни одна запись о сэндбоксе
- **THEN** право не выдаётся

#### Scenario: Владелец репозитория не совпадает с владельцем сэндбокса

- **WHEN** репозиторий из удостоверения принадлежит не тому аккаунту, который записан владельцем сэндбокса
- **THEN** право не выдаётся

### Requirement: Выдаваемое право короткоживущее и только на запись

Токен, выдаваемый сборке, SHALL иметь ограниченный срок действия, достаточный для публикации одного образа, и SHALL давать только право записи в свой образ. Токен MUST NOT давать права чтения чужих образов и MUST NOT быть пригоден для повторного использования после истечения срока.

#### Scenario: Повторное использование просроченного токена

- **WHEN** сборка пытается воспользоваться токеном после истечения срока его действия
- **THEN** реестр отклоняет операцию

### Requirement: Реестр закрыт для анонимного доступа

Реестр MUST NOT позволять анонимное чтение или запись. Скачивание образов SHALL быть доступно только самой платформе.

#### Scenario: Анонимное обращение к реестру

- **WHEN** к реестру обращаются без учётных данных
- **THEN** в доступе отказано и содержимое реестра не раскрывается

#### Scenario: Перечисление образов посторонним

- **WHEN** посторонний пытается получить список образов в реестре
- **THEN** запрос отклоняется
