# auth/github-oauth Specification

## Purpose
Вход в платформу через аккаунт GitHub: получение от пользователя разрешения, достаточного для создания публичного репозитория, с минимальным запрашиваемым доступом и без длительного хранения его токена.

## Requirements

### Requirement: Минимальный запрашиваемый доступ

Платформа SHALL запрашивать у GitHub только доступ, необходимый для создания публичного репозитория в аккаунте пользователя (`public_repo`). Платформа MUST NOT запрашивать доступ к приватным репозиториям, организациям, вебхукам или секретам.

#### Scenario: Экран согласия GitHub

- **WHEN** пользователь перенаправляется на авторизацию GitHub
- **THEN** запрашиваемый набор прав ограничен доступом к публичным репозиториям
- **AND** экран согласия не упоминает доступ к приватным репозиториям

### Requirement: Защита цикла авторизации от подделки

Каждый запуск авторизации SHALL сопровождаться одноразовым непредсказуемым значением `state`, привязанным к браузеру пользователя. Платформа SHALL отвергать callback, в котором `state` отсутствует, не совпадает с ожидаемым или уже был использован.

#### Scenario: Корректный возврат из GitHub

- **WHEN** GitHub возвращает пользователя на callback с `state`, совпадающим с сохранённым для этого браузера
- **THEN** платформа продолжает создание сэндбокса
- **AND** использованное значение `state` становится недействительным для повторного использования

#### Scenario: Подделанный или повторно использованный state

- **WHEN** callback приходит с отсутствующим, несовпадающим или уже использованным `state`
- **THEN** платформа отклоняет запрос, не обращается к GitHub за токеном и показывает ошибку авторизации

### Requirement: Токен пользователя не сохраняется

Токен доступа GitHub SHALL использоваться только в рамках обработки одного callback-запроса. Платформа MUST NOT записывать токен в базу данных, сессию, куки, логи или любое другое постоянное хранилище, и MUST NOT передавать его в браузер.

#### Scenario: Завершение обработки callback

- **WHEN** обработка callback завершена — успешно или с ошибкой
- **THEN** токен доступа больше нигде не доступен платформе
- **AND** ни база данных, ни логи, ни ответ браузеру не содержат значения токена

### Requirement: Сессионная кука ограничена апексом

Если платформа устанавливает куки, они SHALL быть host-only для основного домена платформы. Платформа MUST NOT устанавливать куки с атрибутом `Domain`, распространяющим их на поддомены `zerotomvp.xyz`, поскольку поддомены отдаются под код пользователей.

#### Scenario: Установка куки платформой

- **WHEN** платформа устанавливает любую куку в ответе
- **THEN** кука не содержит атрибута `Domain`
- **AND** кука помечена `Secure`, `HttpOnly` и `SameSite=Lax` или строже

#### Scenario: Запрос из сэндбокса

- **WHEN** код, размещённый на `<sandbox-name>.zerotomvp.xyz`, пытается прочитать куки платформы
- **THEN** куки платформы для него недоступны

### Requirement: Раздельные приложения OAuth для окружений

Каждое окружение платформы SHALL использовать собственное GitHub OAuth App со своим callback URL и своей парой секретов. Секреты MUST NOT попадать в репозиторий и MUST передаваться приложению через окружение.

#### Scenario: Локальная разработка

- **WHEN** разработчик запускает платформу локально
- **THEN** используется OAuth App с callback на локальный адрес
- **AND** учётные данные production OAuth App при этом не используются
